# 🎨 ParchIArte Frontend

Frontend oficial del proyecto **ParchIArte**, desarrollado para la materia *Nuevas Tecnologías del Desarrollo*.  
Esta aplicación está construida con **Angular** y se integra con la API del proyecto para la gestión de actividades, eventos y experiencias culturales.

---

## 📚 Tecnologías

- Angular
- TypeScript
- RxJS
- HTML / SCSS
- Angular Material o Tailwind (según decisión final)
- Git & GitHub

---

## 🛠 Requisitos previos

Instalar:

- **Node.js** (versión LTS recomendada)
- **Angular CLI**

```bash
npm install -g @angular/cli

git clone https://github.com/<tu-usuario>/parchiarte-frontend.git
cd parchiarte-frontend

npm install

ng serve -o

http://localhost:4200

```
